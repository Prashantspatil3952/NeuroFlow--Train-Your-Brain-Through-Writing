# NeuroFlow – Train Your Brain Through Writing

NeuroFlow is a neuroscience-inspired writing application designed to improve focus, creativity, attention span, and mental endurance.

Unlike traditional writing tools, NeuroFlow encourages continuous writing. If the user becomes inactive for 5 seconds, the writing gradually fades and disappears. This creates a sense of urgency that promotes deep focus and flow-state thinking.

---

## Live Features

### Focus Writing Mode

* Continuous writing experience
* 5-second inactivity countdown
* Automatic fade-and-delete effect

### Brain Training Features

## Neuroscience Inspiration

Research suggests that focused writing can help improve:

* Sustained Attention
* Working Memory
* Creative Thinking
* Mental Endurance
* Language Skills
* Cognitive Flexibility

NeuroFlow is designed around these principles to encourage deeper concentration and reduce digital distractions.
